# Codetrail 1.1.1

The page now speaks Arabic. Choose **العربية** in the language picker: the interface reads right to left, keeps technical terms such as commit and branch in English, and writes numbers with Western digits. The guide's own pages stay English, as before; answers and check feedback already come in the language you choose.

## Added

- **An Arabic interface**, translated in full and reviewed. Its catalog ships compiled with Codetrail, so every install offers it, including `uv tool install` from a release tag ([ADR 0013](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.1.1/docs/adr/0013-commit-the-compiled-catalogs.md)).
- **Arabic text set in Noto Sans Arabic**, bundled with Codetrail under the SIL Open Font License, instead of whatever font your system has. Pages load it only when they show Arabic ([ADR 0014](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.1.1/docs/adr/0014-bundle-noto-sans-arabic.md)).

## Fixed

- **The page's own messages follow the interface language**: refusals, the update panel's reasons and a check's verdict were always English.
- **Right to left reads properly**: headings and labels no longer space Arabic letters apart, the Ask and update panels slide in from their own side, search results name their kind in your language and keep the guide's English left to right, and estimates keep their `~` beside the number.

## Install or upgrade

```bash
uv tool install --reinstall git+https://github.com/mohamed-abdelsattar92/codetrail@v1.1.1
```

```bash
codetrail --version
```

Nothing to migrate: your targets, guides and settings carry over as they are. The full list is in the [changelog](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.1.1/CHANGELOG.md).
