# Codetrail 1.3.0

The home page is redesigned to show where you are at a glance, and every link in the guide now opens the page it names, whatever the folder, file or package is called. None of it calls your assistant.

## Changed

- **A redesigned home page** that uses its space and shows more in color. Learning sits in a wide column: where to continue, with a ring for the path's progress; every guided path with its own progress; and the areas, each edged and labelled learned, changed, read or not read yet. Beside it, a rail holds the guide's state against the branch, what changed, the System, Documentation and Repository cards, each in its own color, your saved answers and the folders to browse as chips. The rail moves below the column when the page is narrow, including when the Ask panel takes the room.

## Fixed

- **Links open the page they name, whatever the name holds.** A folder or file with `#` or `?` in its name (such as `docs#1/` or `0002-use-c#.md`), and a module, project or package named that way, now opens from every link to it: the home, area, fact, decisions, system and Repository pages, the boxes of the imports, dependencies, resources and system diagrams, a guide page's fact links and cited lines, and search results. A fact whose name reads as a path, such as an npm dependency named `../../../system`, opens its own page instead of another one. Fact links now encode the `/` in a name as `%2F`; links you saved with a raw `/` still open.
- **The Documentation page opens quickly** the first time after an update on a repository with images under `docs/`: images and other binary files that match the document globs are skipped instead of being read as text, which also stops their bytes from counting as a document mentioning a package.
- **Smaller fixes:** a learned page's green tick in the sidebar shows on its own again, instead of inside a large bordered card; the Repository timeline's "Watched by Codetrail since" label shows in full when its band is narrow; and the arrows on the Documentation page's section headings sit centred on their text.

## Security

- **A repository with many Swift targets and imports can no longer stall an update**: Swift targets are found by name and by folder in one lookup each, instead of a scan of every target.
- **The command palette offers a search result only when its link stays on Codetrail's own page**, judged the way the browser reads the link, so a link such as `/\example.com` (which browsers treat as `//example.com`) can never take you to another site. Codetrail's own results never held such links; this guards against one ever appearing.

## Install or upgrade

```bash
uv tool install --reinstall git+https://github.com/mohamed-abdelsattar92/codetrail@v1.3.0
```

```bash
codetrail --version
```

Your targets, guides and settings carry over unchanged. The full list is in the [changelog](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.3.0/CHANGELOG.md).
