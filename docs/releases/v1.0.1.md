# Codetrail 1.0.1

A patch release: one fix, a security policy, and the rules for contributing.

## Fixed

- **A target that uses Codex without allowing it is refused for that reason first.** Before, when Claude Code wasn't installed, Codetrail reported that instead, and only said why Codex was refused once Claude Code was there. Codex was refused either way; now the reason you see is the one that matters. To use Codex, set `allow_codex = true` under `[assistant]` in the target's settings, after reading what that allows in [Getting started](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.0.1/docs/getting-started.md).

## Added

- **A security policy,** [SECURITY.md](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.0.1/SECURITY.md): how to report a vulnerability privately through GitHub, what to include, and what counts as one.
- **Contribution rules** in [CONTRIBUTING.md](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.0.1/CONTRIBUTING.md): git-flow, every contribution through a pull request, simple code, tests first, commit messages, the changelog, and the contributor licence agreement.

## For contributors

CI now runs on pull requests into `main` as well as `develop`, and passes on GitHub's runners: two tests that depended on the machine they ran on (whether Claude Code was installed, and how long since it booted) no longer do.

## Install or upgrade

```bash
uv tool install --reinstall git+https://github.com/mohamed-abdelsattar92/codetrail@v1.0.1
```

```bash
codetrail --version
```

Nothing to migrate: your targets, guides and settings carry over as they are. The full list is in the [changelog](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.0.1/CHANGELOG.md).
