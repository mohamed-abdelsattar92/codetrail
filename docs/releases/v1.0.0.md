# Codetrail 1.0.0

**Turn a git repository into a local learning guide that keeps up with it.**

This is Codetrail's first public release. Codetrail is for the person responsible for a repository that changes faster than they can follow. It reads the code into facts, has the assistant you already pay for write a guide from them, and serves that guide as a local web page: concept pages tied to the real code, guided paths, digests of what changed and why, checks on your understanding, and progress that notices when what you learned has gone stale.

## Highlights

- **Grounded, not guessed.** Deterministic extractors turn the code into facts (Python, TypeScript, JavaScript and Astro, OpenAPI, Terraform, Swift packages, GitHub Actions and ADRs). Diagrams are drawn from those facts only, with the file and line behind every arrow. Rationale quoted from an ADR or a commit is checked against the source and marked documented; the assistant's own reading is marked inferred.
- **Your system on one page.** How the repository's services, apps, libraries, contracts and infrastructure connect, and where they run.
- **Keeps up with you.** Each update says what changed and why in a digest, writes the pages your new commits touched first, and revises a page section by section when only a few things changed in it. A "you're behind" signal, computed from git alone, says when it's time.
- **Ask from any page.** Questions go to your assistant with read-only tools, and answers worth keeping are saved to the guide.
- **Learn, and know when it went stale.** Guided paths, checks graded against rubrics grounded in the code, and pages that show what changed since you learned them.
- **Your assistant, your subscription.** Claude Code on a Claude subscription (the default), Codex on a ChatGPT subscription, or a free local model through Ollama or LM Studio.
- **No surprise costs.** Every paid action shows its estimate first (each page it will write, and why) and stops at its budget. The update panel shows each step as it happens.
- **Secrets stay out.** Codetrail reads only committed files, and drops secret files, your ignore rules and everything gitleaks flags before any extractor or assistant sees them (except Codex, for a target that opts in to it). It scans every page and answer again before saving it; Codex's and local models' answers are also held back until the scan passes. It never reads, stores or passes a key or token, unless you set `auth = "api_key"`, when the provider's key variable is handed to its program by name. It never writes to the repository it teaches.
- **Local by default.** The page listens on 127.0.0.1 only, behind a single-use login and a per-session token. There's no hosted service and no database server.

## Install

You need [uv](https://docs.astral.sh/uv/), [gitleaks](https://github.com/gitleaks/gitleaks) on your `PATH`, and one assistant: [Claude Code](https://code.claude.com/docs/en/setup), Codex, or Ollama or LM Studio. Codetrail runs on macOS and Linux, and uv installs the Python it needs (3.14).

```bash
uv tool install git+https://github.com/mohamed-abdelsattar92/codetrail@v1.0.0
```

```bash
codetrail --version
```

Then follow [Getting started](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.0.0/docs/getting-started.md): connect an assistant, add a repository, build the guide and open it. It takes about ten minutes, plus the time the first update runs.

## Good to know

- **Codex is off unless a target opts in.** Codetrail can't confine Codex's reads to the filtered sources the way it confines Claude Code's and local models': once a target opts in, Codex can read anything you can, including the files Codetrail hides and your own keys, and sends what it reads to OpenAI before Codetrail's scan sees it. Getting started explains the trade-off.
- **The first update is the biggest.** It plans the outline and writes up to `max_pages_per_update` pages (20 by default); later updates pick up the rest. Estimates start from built-in guesses and use your own call history once there is some.
- **The guide's pages are in English.** The interface can be translated with gettext catalogs, right-to-left languages included, and ships in English; live answers and check feedback come back in the language you choose.
