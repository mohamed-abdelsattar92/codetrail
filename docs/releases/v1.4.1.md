# Codetrail 1.4.1

Codetrail is now published to PyPI, as `codetrail-cli`, and its README says plainly what it's for: getting up to speed on a codebase you're new to, on your own or as a team, with your coding agent alongside. Nothing changes in how Codetrail works.

## Changed

- **Codetrail is published to PyPI as `codetrail-cli`.** PyPI's `codetrail` belongs to an unrelated project, so the package takes another name; the command is still `codetrail`. Each release from this one on is published to PyPI from GitHub Actions, by trusted publishing, so no upload token exists anywhere ([ADR 0019](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.4.1/docs/adr/0019-publish-to-pypi-as-codetrail-cli.md)).
- **The installed tool is named `codetrail-cli`**, however you install it: from PyPI, a release tag or a clone. If you installed 1.4.0 or earlier, uninstall the old `codetrail` tool once first, as below: both put a `codetrail` command on your `PATH`.
- **The README leads with who Codetrail is for**: someone who just joined a team, a team that inherited a project, and whoever brings people onto a codebase. It opens with a four-line quick start.

## Security

- **The workflow that publishes each release checks what it installs.** It installs mise only by a checksum pinned in the workflow, and Python and uv only by the checksums in `mise.lock`, in a job that restores no cache and waits for the maintainer's approval. CI does the same for its tools, except d2, which publishes no checksums.

## Install or upgrade

If you installed 1.4.0 or earlier:

```bash
uv tool uninstall codetrail
```

Then install this release:

```bash
uv tool install git+https://github.com/mohamed-abdelsattar92/codetrail@v1.4.1
```

```bash
codetrail --version
```

Once the README's quick start installs from PyPI, `uv tool install codetrail-cli` works too, and `uv tool upgrade codetrail-cli` keeps a PyPI install current.

Your targets, guides and settings carry over unchanged: they live in Codetrail's own folders, which uninstalling the tool doesn't touch. The full list is in the [changelog](https://github.com/mohamed-abdelsattar92/codetrail/blob/v1.4.1/CHANGELOG.md).
